# Coding Standards & Project Conventions

## Overview

Establishes coding conventions, language constraints, linting parameters, and schema-first modeling rules for the codebase.

## Core Concepts

- **Languages**: Python (3.11+ / 3.14+) and C++ exclusively. No bash/shell scripts in source control.
- **Model Generation**: Zero hand-written models. Models are autogenerated from `schemas/` via `datamodel-code-generator`.
- **Logging**: Zero default stdout/stderr output. Use `loguru` with sink configuration.
- **Linting & Formatting**: Ruff ALL rules (`select = ["ALL"]`) and Ty strict typing configured in `pyproject.toml`.
- **Tooling**: All tools explicitly pinned in `.mise.toml` without `"latest"`.

## Relationships & References

- Enforced locally via `hk check` and `mise run check`.
- Verified in CI via `.github/workflows/ci.yml`.
