# Tests Directory (`tests/`)

Contains async unit tests using `pytest` and `pytest-asyncio`:
- `test_graph.py`: Knowledge graph extraction unit tests.
- `test_models.py`: Autogenerated Pydantic model validation.
- `test_okf.py`: Open Knowledge Format specification tests.
- `test_orchestration.py`: Multi-agent workflow planner tests.
- `test_serializer.py`: MsgPack binary and orjson serialization tests.
- `test_telemetry.py`: Telemetry collector JSONL/MsgPack tests.
- `test_verify.py`: Environment verifier and toolchain pinning tests.
- `test_context_manager.py`: Context window evaluation (<50% threshold) tests.
